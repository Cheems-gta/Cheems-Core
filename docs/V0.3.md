# V0.3 development status

V0.3 is under development. There is no V0.3 release APK yet.

The user's real subscription contains 56 AnyTLS and 9 Hysteria2 nodes. V0.2 can parse their Clash YAML records but cannot connect to them. No record will be relabelled supported until a working adapter is connected.

Implemented in the first development checkpoint:
- Preserve AnyTLS and Hysteria2/hy2 sharing-link authentication, SNI, ALPN and Hysteria2 Salamander options.
- Fix newline and whitespace handling for multiple URI records and wrapped Base64 subscriptions.
- Preserve the existing explicit unsupported status until transport implementation is present.

Release goals, all pending:
1. AnyTLS TLS, settings negotiation, reusable sessions, padding updates, stream lifecycle and UDP-over-TCP compatibility.
2. Hysteria2 authentication, QUIC, TCP/UDP, TLS/SNI, Salamander, connection timeouts and network changes.
3. Android VpnService permission, protected gateway sockets, TUN descriptor ownership, packet processing, DNS and IPv4/IPv6 routing.
4. Expand protocol adapters for SS (including AEAD-2022), Trojan, VMess, VLESS/Reality, TUIC, HTTP and SOCKS5 with explicit transport/feature capability reporting.
5. Verify end-to-end traffic and stop/revoke cleanup before publishing a V0.3 APK.

The engine must not depend on the Mihomo runtime. Using maintained protocol or packet-processing libraries must remain visible in dependencies and attribution; no upstream engine may be renamed and described as wholly original code. All networking security primitives remain platform or established library implementations.

Subscription import compatibility, protocol implementation and verified connectivity are separate states. Future UI changes must preserve this distinction.
